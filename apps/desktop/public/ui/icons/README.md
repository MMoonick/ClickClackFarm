# ClickClackFarm 管理界面图标

本目录包含管理层和主窗口控制使用的 `16` 个单色 SVG 图标。图标来自 Lucide `1.27.0`，仅按项目资源 ID 重命名，几何内容未修改。

## 接入规则

- 默认设计尺寸为 `24 × 24 pt`，允许在 `16/20/24 pt` 使用。
- 图标使用 `currentColor`，颜色由客户端状态控制。
- 普通状态使用正文次级色；当前导航项与主要操作使用强调色。
- 禁用状态降低不透明度，不另外制作 SVG。
- 图标按钮的可点击区域不得小于 `32 × 32 pt`；关闭按钮建议使用 `36 × 36 pt`。
- 不要同时叠加文字轮廓、投影或多色填充。
- 主画面只使用 `icon-window-drag` 的六点图形，并把它无底框地放在仓库右上角；`icon-window-hide` 保留为历史/系统设置素材，不再进入主画面。不得把拖拽图标用作土地、植物或动物操作。

具体资源与 Lucide 原图标名称见 `icon-manifest.json`；授权全文见 `LICENSE-LUCIDE.txt`。
